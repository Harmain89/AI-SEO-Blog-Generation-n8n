Automated SEO Blog Generation System - n8n + OpenAI + Full-Stack Web App

Built a system that writes and publishes a fresh tech blog article every single day - fully automatically, zero human involvement. It scans trending headlines via Google News, writes a 900–1,100 word journalist-quality article using GPT-4o-mini, generates a featured AI image, pulls real stock photos, and publishes everything to a custom-built blog website (React + Node.js + MySQL) through a secured API.

The entire pipeline runs on n8n at ~$1.50/month in API costs - replacing what would otherwise cost hundreds of dollars in content writing fees. Built for businesses, agencies, and startups who need consistent SEO content without hiring a writer.
